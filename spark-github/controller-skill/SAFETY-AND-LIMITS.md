# Safety and Limits

## What this system does

- stores REEF-compatible harness trees in GitHub;
- lets Spark propose text/config candidates through GitHub tools;
- uses GitHub Actions for deterministic validation and ZIP packaging;
- records A/B evaluation results;
- promotes only an explicitly approved candidate.

## What no-API mode does not do

It does not run REEF's autonomous proposer/evaluator loop inside GitHub Actions. The interactive Gemini Spark subscription is not treated as a server-side API credential.

A candidate created by Spark must be described as `Spark-proposed, REEF-compatible`, not as autonomously generated by REEF.

## Optional autonomous REEF

Full REEF `harness-evolve`/Reefine style automation requires a programmatic model endpoint that GitHub Actions or another runtime can call. That can be added later as an explicit paid/free-API mode, with separate secrets and budgets. It is disabled in this starter.

## Executable nodes

Never convert Reef code/native nodes into text and claim equivalent execution. The Spark exporter rejects them.
